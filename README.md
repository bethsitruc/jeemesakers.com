# Jeemes Akers

This repository contains the source code for the official Jeemes Akers website.

## Visit the Site

- Website: https://www.jeemesakers.com

## About This Repository

This project is maintained for the Jeemes Akers website by Bethany Curtis and authorized collaborators. It is not open for public installation, redistribution, forks, or unsolicited code contributions.

The site includes the public web experience, long-form Missives content workflow, and supporting assets for the published site.
